# EasyTier Flutter 真实 Demo

这个示例直接启动内嵌 EasyTier 核心，并显示运行状态、虚拟 IP、已连接节点、流量和日志。默认 TOML 使用占位网络名、密钥和 peer，运行前请替换为自己的组网信息。

## Windows 测试

```powershell
cd example
flutter run -d windows
```

以管理员身份启动终端，否则 Windows 无法创建或使用虚拟网卡。打开页面后点击“校验”，再点击“启动新组网”。

## Android 测试

```powershell
cd example
flutter run -d android
```

也可以直接安装已经构建的 `build/app/outputs/flutter-apk/app-debug.apk`。首次点击“启动新组网”时，系统会弹出 VPN 授权框；同意后 Demo 会自动继续，不需要再次点击。Android 当前限制为一个 VPN 会话。

## 修改配置

页面中央的编辑器就是实际传给核心的 TOML。两台设备要加入同一个网络，必须使用相同的 `network_name` 和 `network_secret`，并保证至少一个 `peer` 可以访问。示例中的值只是占位符，无法直接连接。

原生集成测试位于 `integration_test/simple_test.dart`。

已完成的真机验证与待测项目见 [测试记录](../docs/TESTING.md)。

## 多组网测试

Windows 以管理员身份运行后，用第一份配置点击“启动新组网”，修改为第二份配置，再点击“启动新组网”。两份配置请使用不同的虚拟 IP；如果指定监听端口，也要使用不同端口。不同网络建议使用不同的网络名和虚拟网段。

“组网实例”显示各实例的状态、IP 和节点数。点击实例即可切换查看，编辑框也会切换到该实例保存的配置草稿。“刷新”“重启”“停止”只操作当前选中的实例；“停止全部”会停止全部实例，之后仍可重新启动。

建议验证以下操作：

- 同时启动两个组网，分别访问各自的节点。
- 切换实例，确认节点列表和流量属于选中的组网。
- 停止或重启其中一个，确认另一个仍能访问。
- 使用相同静态虚拟 IP 或监听端口，确认出现明确冲突提示。
- 点击“停止全部”，确认全部停止后可以再次启动。

Android 同时只能运行一个系统 VPN 会话，启动第二个会得到明确提示。页面重建后恢复的原生实例没有配置原文，编辑框会显示默认占位配置；重启前需要重新填写配置。Demo 的配置草稿只保存在当前页面内存中。
